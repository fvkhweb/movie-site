# План развития «Что посмотреть?» (movie-site)

Цель: превратить простую витрину фильмов в полноценный каталог с фильтрами, актёрами
и нормальной работой из РФ без VPN (всё статичное, GitHub Pages, без бэкенда).

## Принципы

1. **Работа без VPN** — постеры хранятся прямо в репозитории и отдаются с домена сайта.
   Сторонние картинки (фото актёров) идут через бесплатный прокси `wsrv.nl`.
2. **Без бэкенда** — GitHub Actions собирает данные из API (TMDB + Кинопоиск) и коммитит их в репо.
3. **Данные небольшими файлами** — чтобы страница не грузила мегабайты зря.

## Текущее состояние (v2, готово)

- Каталог `data/movies.json` (~1500 фильмов): название, год, рейтинг TMDB/КП, жанры,
  длительность, страны, описание, постер (локальный файл) + резервная ссылка.
- `data/cast.json` — актёры по каждому фильму (имя, роль, фото).
- `data/people.json` — индекс актёров: имя, фото, в каких фильмах снимался.
- `data/lists.json` — списки «Популярное», «Топ по рейтингу».
- `data/genres.json` — справочник жанров (id → название).
- Сборка: `scripts/fetch_movies.py` (TMDB: popular, top_rated, discover по жанрам;
  Кинопоиск: описание/рейтинг/постер-резерв для лимитированного числа фильмов —
  у бесплатного тарифа ~200 запросов/сутки).

## Фаза 1 — витрина (текущая задача)

- [x] Табы: Популярное / Топ / Каталог / Избранное.

- [x] «Случайный фильм», избранное в localStorage, бесконечная прокрутка.
- [x] Заглушки-скелетоны, аккуратные пустые состояния.

## Фаза 2 — расширение данных

- [ ] Сериалы (`/tv/*` в TMDB): отдельная вкладка, свои фильтры (сезоны, статус).

## Ограничения, о которых надо помнить

- **Кинопоиск (api.kinopoisk.dev)** — бесплатный тариф ~200 запросов/сутки:
  обогащаем ограниченное число фильмов за прогон (`KP_MAX_MOVIES`), остальные — в следующий день.
- **Репозиторий**: ~30 КБ на постер; при 1500 фильмах это ~40 МБ. Старые постеры,
  ушедшие из каталога, чистим скриптом, чтобы репозиторий не пух вечно.
- **TMDB API** недоступен из РФ напрямую — только на GitHub Actions, из РФ сайт работает
  потому, что данные уже лежат в репозитории.
- **GitHub Pages** отдаёт статику с задержкой ~1–2 минуты после пуша.
